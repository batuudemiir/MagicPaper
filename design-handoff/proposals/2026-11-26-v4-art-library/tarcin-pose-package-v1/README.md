# Tarçın V4 poz paketi

Altı ayrı PNG; index.html kaynak sayfalarla birlikte açılır. Yerleşik imagegen, V4 kimlik çizimi, onaylı marka ve gereken nesne referansları kullanıldı. Tam promptlar üst klasörde TARCIN_POSE_GENERATION_RECORD.json içindedir.

Bu çizimler henüz runtime onayı taşımaz. Beyaz/gece kompoziti, küçük okuyucu boyutu ve tam sayfa uyumu uygulama entegrasyonundan önce incelenmelidir. Önceki çizimler, motor ve kayıtlı kitaplar değişmez.
