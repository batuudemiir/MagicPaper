# MagicPaper V4 nesne paketi 1

15 ayrı şeffaf PNG; index.html ile açılır. Onaylı marka referansıyla yerleşik imagegen kullanıldı. İlgili tam promptlar üst klasörde SHARED_GENERATION_RECORD.json, OBJECT_GENERATION_RECORD.json ve CONTACT_CORRECTION_RECORD.json içinde. İlk kopuk temas çizimi seçilmedi.

Kaynak listeleri aday kullanım yerleridir, runtime eşleşmesi değildir. Minder/örtü/mendil gibi rengi metinde belirtilmeyen nesnelerin rengi bu paketin sanat tercihidir; aynı nesnenin sonraki çiziminde korunmalıdır. Çanta kimliği Böğürtlen referansından gelir. Karakter pozları dahil değildir. Paket metinleri, motor seçimini veya kaydedilmiş kitapları değiştirmez.

Yalnız bu 15 pilot kitaba göre seçilmiştir; tüm V4 kitapları veya yaş grupları için yeterlilik garantisi yoktur. Yayın öncesi ilgili sayfa, görsel, küçük boyut ve beyaz/gece kompoziti birlikte incelenmelidir.
