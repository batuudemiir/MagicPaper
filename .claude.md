# MagicPaper - AI Story Generator for Kids

## 🎯 Project Overview

MagicPaper is an iOS app that creates personalized, AI-generated stories for children aged 3-12. The app uses Google's Gemini AI to generate stories with the child as the main character, featuring their photo in illustrated pages.

### Core Value Proposition
- **Personalized Stories**: Child becomes the hero of their own adventure
- **AI-Powered**: Uses Gemini 1.5 Flash for story generation and image creation
- **Educational**: Promotes reading habits and imagination development
- **Safe**: COPPA compliant, Kids Category approved
- **Multi-language**: Turkish and English support

## 📱 App Architecture

### Technology Stack
- **Platform**: iOS 15.0+, iPadOS support
- **Language**: Swift, SwiftUI
- **AI**: Google Gemini 1.5 Flash API
- **Storage**: Local file system (FileManager)
- **Monetization**: Auto-renewable subscriptions (3 tiers)

### Key Features
1. **Story Generation**
   - Text-only stories (unlimited for free users with 12h cooldown)
   - Illustrated stories (subscription required)
   - Daily stories (curated content)
   
2. **Personalization**
   - Child profile with photo
   - Age-appropriate content (3-12 years)
   - Multiple themes (fantasy, adventure, space, forest, etc.)
   - Story length options (short, medium, long)

3. **Reading Experience**
   - Book-like page turner interface
   - Customizable text size, theme, line spacing
   - High contrast mode for accessibility
   - Auto-play option
