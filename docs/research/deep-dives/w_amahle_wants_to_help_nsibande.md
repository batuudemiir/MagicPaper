## Repetition

- refrain: 'No, Amahle, you are too young.' — the same line on five spreads — functions participation, anticipation, rhythm; effective: True — the words never change but the pictures darken, so the feeling grows while the text stays predictable
- phrase: 'But <adult> says...' ends every request spread; the last one is 'And Mama says...' — functions participation, anticipation; effective: True — one changed word signals the break in the pattern

## Visual storytelling

- Refusal spreads reuse one composition; only the background colour and scribbles change, and they darken each time — the escalation is carried by the picture alone.
- The final spread releases the blue into a full-colour sky.

## Strengths

- escalation carried by colour
