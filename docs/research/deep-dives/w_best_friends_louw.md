## Summary (paraphrase)

Two inseparable bushbaby friends turn down every other classmate; when one is ill, the other is drawn in by a classmate making a get-well card, plays with everyone, and on the friend's return helps the friend accept the new circle.

## Repetition

- structure: three invitations in a row, each declined with the same reply shape — functions anticipation, participation; effective: True — builds a pattern the reader can predict, which the illness breaks and page 8 reverses
- phrase: the same polite refusal line opens Zindzi's reply three times — functions participation, rhythm; effective: True — easy to join in; its absence later marks the change
- phrase: a short painting chant spoken by both characters — functions rhythm, participation; effective: True — the echoed chant is the moment the two become partners
- callback: each classmate who was declined is played with in turn (dress-up and scooters return; the hare's game becomes hopscotch) — functions memory; effective: True — the reversal is enacted, not stated
- callback: title phrase 'best friends' returns widened to the whole group — functions memory, comfort; effective: True — closes the arc by redefining the opening words

## Visual storytelling

## Strengths

- a three-part pattern set up, broken and then reversed by action
- the friendship problem is felt from both sides (left-out, then replaced)

## Weaknesses
