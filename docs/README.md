# MagicPaper — belgeler

Güncel belgelerin tek listesi. Yol haritası `MagicPaper_Faz_Plani_Ekim.md`'dir; başka bir belge onunla
çelişirse plan geçerlidir. Proje kuralları ve tasarım yasası üst klasördeki `CLAUDE.md`'de.
Geçerliliğini yitiren raporlar `retired/` altında durur (yalnızca tarihçe için).

## Plan ve süreç

| Belge | Ne anlatır |
|---|---|
| `MagicPaper_Faz_Plani_Ekim.md` | Etkin yol haritası (Faz 9 ve sonrası), değişmeyen kurallar, karar özeti |
| `MagicPaper_Faz_Plani.md` | Faz 0–8 ve açık maddeleri (Ekim planı bunun devamı) |
| `CLAUDE_CODE_PROMPTLARI.md` | Faz başına Claude Code promptları |
